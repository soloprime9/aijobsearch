Questions people ask

What do I get for $5?

A ready-to-run package: launchers, a step-by-step guide and setup help, so you skip the trial and error and make your first clip in minutes. It is built on the AutoClip engine, a tool with 10.8k stars on GitHub.

Do I need an API key?

For cloud AI models, yes. You use your own key and pay your provider by usage (the AutoClip team measured about $0.01 of text-model cost for a 1h43m video). Local models through Ollama or LM Studio need no cloud key but need a capable computer. The built-in sample project works without any key.

Which computers work?

Desktop app: Windows 10/11 (x64) and macOS on Apple Silicon. Intel Mac and Linux can use Docker web mode or CLI.

Are my videos uploaded anywhere?

Cutting and rendering happen on your own computer. If you pick a cloud AI or cloud transcription service, the subtitles, sampled frames or audio needed for that step are sent to that provider.

Will it work on any video?

It works best on interviews, podcasts, courses and talking-head videos. Gaming or low-speech videos need image recognition turned on, and you should always check the chosen moments.
